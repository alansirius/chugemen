# 周末城市探索指南

## 题目

周末城市探索指南

## 背景

大学生周末常纠结"去哪玩"——展览、市集、演出、短途徒步等活动信息分散，且受天气、预算、同行人数影响大。

## 任务

使用 AI Coding 工具，设计一个「周末城市探索指南」，根据用户偏好、天气、预算推荐本地活动，支持组队出发、打卡记录、攻略分享。

## 已实现：出个门

移动端优先的城市探索 Web 应用，桌面自适应。原生 ES Modules + CSS 前端，Node.js HTTP API，SQLite 持久化，无第三方运行时依赖。需要 Node.js 22.13+；已在 Node.js 25.5 验证，此版本的 node:sqlite 会输出实验性功能提示。

### 启动

```sh
npm start
```

访问 http://127.0.0.1:3000 。开发时使用 `npm run dev`，测试使用 `npm test`。数据库首次运行自动初始化到 `data/app.sqlite`，含 8 篇杭州示例记录。通过 `DB_PATH`、`PORT`、`HOST` 设置数据库路径与监听地址。

### 功能

- 浏览：双列移动端图文流、搜索、分类、预算/时长/距离筛选、关注动态、推荐理由。
- 定位：用户主动开启 Geolocation watchPosition，支持停止定位；未授权时使用明确标注的杭州默认位置。
- 天气：服务端请求 Open-Meteo，10 分钟缓存，失败时明确提示不可用，不虚构天气。
- 推荐：Haversine 距离、兴趣匹配、室内外天气适配、可用时间加权排序，预算/半径/时长硬筛选。
- 发布：图片压缩、图文、地点坐标、分类、人均预算、游玩时长、室内属性，保存至 SQLite。
- 社交：个人主页、兴趣编辑、关注与互关好友、点赞、评论、带原帖引用的转发。
- 组团：未来出发时间、人数限制、发起人自动加入、拒绝重复加入及超员。
- 聊天：双方私聊持久化，3 秒轮询更新；只有会话参与者能读取对应消息。
- 帐号：注册、登录、退出，scrypt 密码哈希，HttpOnly/SameSite 会话 Cookie；支持独立体验帐号。

### 文件

- `server.mjs`：数据库初始化、HTTP API、静态资源服务。
- `recommend.mjs`：可解释的推荐与距离计算。
- `seed.mjs`：带示例标记的杭州内容。
- `public/index.html`、`public/style.css`、`public/app.js`：页面、响应式样式、交互。
- `public/manifest.webmanifest`：主屏幕应用元数据。
- `tests/app.test.mjs`：7 组自动化测试，使用临时独立数据库。

### 当前边界

这是本地可运行的 MVP，尚未上线或打包为 iOS/Android 原生应用。Manifest 已配置，没有 Service Worker 或离线缓存。手机远程访问须自行配置监听地址及 HTTPS；浏览器定位通常要求 HTTPS 或 localhost。

示例内容集中在杭州，远离杭州时可能没有附近结果；可扩大筛选范围或发布当地记录。示例作者没有真人值守，私聊不会自动回复。配图来自 Unsplash，仅作氛围示意，不保证是对应地点的实拍。预算、营业时间与活动安排尚未接入商业地点供应商，需用户核实。

时间因素目前指用户可用游玩时长，不包含场所营业时段与节假日预测。位置仅用于当前浏览；发布时用户须确认地点坐标。天气请求会将查询坐标发送给 Open-Meteo。聊天为轮询，尚无推送通知、已读回执或群聊。图片以压缩后的 Data URL 保存在数据库，规模化时需迁移至对象存储。

上线前需补充登录限流、内容审核/举报、帐号恢复、数据备份、上传存储及监控，并在 HTTPS 环境配置 `COOKIE_SECURE=1`。部署多实例时需重新设计数据库并发及消息更新机制。

自动化接口测试已通过；浏览器工具检查受阻，尚未完成实际手机视觉与定位授权验收。

技术参考：[Node.js SQLite](https://nodejs.org/api/sqlite.html)、[Open-Meteo](https://open-meteo.com/en/docs)。


### 演示模式更新

浏览页移除顶部宣传横幅，直接呈现分类、筛选与推荐帖子。好友页展示互关好友的帖子，顶部头像可进入好友主页。

首次访问自动进入独立体验帐号，包含 3 位互关好友、3 组双向聊天和 3 篇个人游记（附点赞、评论）。聊天及主页标注演示性质，预置角色不会自动回复。数据持久化且只初始化一次，旧体验帐号刷新后会补齐；注册帐号不自动填充虚拟数据。不同体验帐号的个人记录不会混入彼此的推荐页。

退出后本次浏览会保留未登录状态；可通过登录弹窗中的体验帐号按钮重新进入演示。后端文件有更新时需重启 `npm start`。

旧体验帐号的数据迁移现在会在服务启动时自动执行，访问已登录接口时也会检查，不再依赖浏览器重新调用 `/api/me`。HTML/JS/CSS 禁用 HTTP 缓存以便本地演示及时更新。
